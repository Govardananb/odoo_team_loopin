# Traveloop

Traveloop is a modern travel planning platform developed for the **Odoo x KAHE Coimbatore Hackathon '26**.

The platform helps users plan and organize trips through itinerary building, destination exploration, activity management, and budget tracking within a clean and immersive user experience.

---

## Features

- User Authentication
- Dashboard & Trip Overview
- Multi-City Trip Planning
- Destination Search
- Itinerary Builder
- Activity Explorer
- Budget & Cost Tracking
- Public Itinerary Sharing

---

## Design Approach

Traveloop follows a minimal and cinematic design approach focused on:

- Clean user experience
- Modern dark interface
- Responsive layouts
- Smooth interactions
- Intuitive navigation
